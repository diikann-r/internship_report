**On this page**, you will need to introduce your worklog. **How** did you complete it? How many weeks did you take to complete the program? **What** did you do in those weeks?

Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period) with weekly contents as follows:

**Week 1:** [Getting familiar with AWS, setting up account, and exploring core services (IAM, S3, EC2)](1.1-week1/)

**Week 2:** [Introduction to Serverless Architecture on AWS (Lambda, API Gateway, DynamoDB)](1.2-week2/)

**Week 3:** [Requirement analysis, designing system architecture, and writing the project proposal (Proposal)](1.3-week3/)

**Week 4:** [Setting up AWS infrastructure and building the invoice upload flow (API Gateway, Upload Lambda, S3)](1.4-week4/)

**Week 5:** [Researching and integrating OCR service (Amazon Textract) for document text extraction](1.5-week5/)

**Week 6:** [Integrating OpenAI API to analyze and structure OCR text into JSON format](1.6-week6/)

**Week 7:** [Setting up Amazon DynamoDB database and storing processed invoice records](1.7-week7/)

**Week 8:** [Building invoice management REST APIs (GET/PATCH for tags and starred status updates)](1.8-week8/)

**Week 9:** [Initializing the ReactJS frontend project and integrating Amazon Cognito for user authentication](1.9-week9/)

**Week 10:** [Building the Dashboard interface, invoice lists, details, and search/filter functionality](1.10-week10/)

**Week 11:** [Integrating advanced features (Excel export, custom tags, starred) and conducting end-to-end testing](1.11-week11/)

**Week 12:** [Performance testing, CloudWatch logging configuration, deploying to AWS Amplify Hosting, and final report writing](1.12-week12/)
