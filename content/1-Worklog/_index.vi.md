**Trong trang này** bạn sẽ cần giới thiệu worklog của bạn **như thế nào**? Bạn hoàn thành chương trình trong vòng **bao nhiêu tuần**? Bạn **đã làm gì** trong các tuần đó?


Thông thường và cũng là tiêu chuẩn, một worklog được thực hiện trong khoảng 3 tháng (trong suốt thời gian thực tập) với nội dung các tuần như sau:

**Tuần 1:** [Làm quen với AWS, thiết lập tài khoản và tìm hiểu dịch vụ cơ bản (IAM, S3, EC2)](1.1-week1/)

**Tuần 2:** [Tìm hiểu kiến trúc Serverless trên AWS (Lambda, API Gateway, DynamoDB)](1.2-week2/)

**Tuần 3:** [Phân tích yêu cầu, thiết kế kiến trúc hệ thống và viết bản đề xuất (Proposal)](1.3-week3/)

**Tuần 4:** [Thiết lập hạ tầng AWS và xây dựng luồng Upload hóa đơn (API Gateway, Upload Lambda, S3)](1.4-week4/)

**Tuần 5:** [Nghiên cứu và tích hợp dịch vụ OCR (Amazon Textract) để trích xuất văn bản](1.5-week5/)

**Tuần 6:** [Tích hợp OpenAI API để phân tích và cấu trúc hóa dữ liệu hóa đơn thành JSON](1.6-week6/)

**Tuần 7:** [Thiết lập cơ sở dữ liệu Amazon DynamoDB và lưu trữ dữ liệu hóa đơn đã xử lý](1.7-week7/)

**Tuần 8:** [Xây dựng các API quản lý hóa đơn (GET, PATCH cập nhật tags và trạng thái starred)](1.8-week8/)

**Tuần 9:** [Khởi tạo dự án Frontend ReactJS và tích hợp xác thực người dùng bằng Amazon Cognito](1.9-week9/)

**Tuần 10:** [Xây dựng giao diện Dashboard, danh sách, chi tiết hóa đơn và tính năng tìm kiếm, bộ lọc](1.10-week10/)

**Tuần 11:** [Tích hợp các tính năng nâng cao (xuất file Excel, gắn thẻ tags, đánh dấu starred) và kiểm thử liên thông (End-to-End)](1.11-week11/)

**Tuần 12:** [Kiểm thử hiệu năng, cấu hình ghi log với CloudWatch, triển khai dự án lên AWS Amplify Hosting và viết báo cáo tổng kết](1.12-week12/)
