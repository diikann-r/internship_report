### Week 3 Objectives:

* Understand basic Amazon EC2 features: Instance Type selection, AMI management, Backup, Key Pair, and Elastic Block Store (EBS).
* Practice creating and configuring virtual servers on AWS.
* Establish data storage and backup with EBS.
* Configure connection security on AWS.

### Week 3 Achievements:

* Mastered fundamental EC2 features: Instance Types, AMIs, Key Pairs, and EBS.
* Successfully initialized, configured, and connected via SSH to the EC2 instance.
* Managed data storage and backup using EBS:
  * Created EBS snapshots.
  * Created AMIs from snapshots.
  * Developed and verified backup and recovery strategies.
* Configured connection security according to best practices:
  * Implemented SSH hardening.
  * Detailed configuration of Security Groups inbound/outbound rules.
