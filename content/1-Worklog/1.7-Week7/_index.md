### Week 7 Objectives:

* Containerize applications using Docker, and build and manage Docker Images for deployment on AWS.
* Deploy containerized applications on Amazon Lightsail Containers and Amazon EKS; configure runtime environments, system resources, and verify application operations.
* Migrate monolithic applications to microservices using Docker and AWS Fargate; deploy independent services and evaluate system scalability.
* Build CI/CD pipelines utilizing AWS CodePipeline and GitHub to automate building, testing, and deploying containerized applications.
* Configure monitoring, manage resource allocation, and implement security measures for container environments to ensure system stability and safety.
